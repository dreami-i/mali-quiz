# 악성메일일까? 정상메일일까? — 모의훈련 인식제고 퀴즈 (Vercel 버전)

Next.js(App Router) 기반의 악성메일 모의훈련 퀴즈 웹앱입니다.
클라우드 배포용으로 만들어졌으며 Vercel에 바로 올릴 수 있습니다.

## 주요 기능
- 메인 화면: "악성메일일까? 정상메일일까?" / "악성메일 원천 방어" + 방어 애니메이션
- 9문항 문제풀에서 매번 5문항을 랜덤 출제 (5지선다)
- 문제별 힌트 보기 버튼, 정답 시 부연설명 팝업("방어 성공"), 오답 시 경고 팝업("방어체계 위기 !")
- **이전 문제로 돌아가기**: 진행 중 이전 문항으로 돌아가 답을 다시 선택할 수 있음
- 5문제 만점 시 "미션 성공" + 참가자 번호(1~33, 밝은 노란색 표기) 또는 **TEST**(핑크색 표기) 입력으로 등록
- `/stats` 페이지: 참가자/미참가자 번호를 구분해서 보여주는 통계 화면, **TEST 응시 횟수는 별도 카운터로 집계**
- **통계 초기화**: `/stats` 페이지의 "⟲ 초기화" 버튼 → 비밀번호(`123123`) 입력 시 전체 참가자 데이터 삭제
- 퀴즈 화면 주변에 방패·자물쇠·엄지척·반짝임 등 경쾌한 장식 아이콘 애니메이션

## TEST 계정 동작 방식
- 결과 화면에서 참가자 번호 선택 목록에 `TEST (테스트 계정)` 항목이 포함되어 있습니다.
- 일반 참가자 번호(1~33)는 "등록 여부"만 의미가 있어 같은 번호로 여러 번 제출해도 1건으로 처리됩니다.
- `TEST`는 여러 번 눌러서 테스트할 수 있도록, 제출할 때마다 **누적 카운트**가 올라갑니다.
- 통계 화면(`/stats`)에는 참가자 33명 현황과 별개로 **"TEST 응시 횟수"** 카드가 따로 표시됩니다.

## 로컬 실행
```bash
npm install
npm run dev
```
`http://localhost:3000` 에서 확인할 수 있습니다.
(로컬/KV 미연결 상태에서는 데이터가 서버 메모리에만 저장되며, 서버 재시작 시 초기화됩니다.)

## Vercel 배포 방법

### 1) 저장소 업로드 & 배포
1. 이 폴더를 GitHub 저장소로 push 합니다.
2. [vercel.com](https://vercel.com) 에서 `New Project` → 방금 만든 저장소를 Import 합니다.
3. Framework Preset은 Next.js가 자동으로 감지됩니다. 별도 설정 없이 `Deploy`를 누르면 됩니다.

또는 Vercel CLI를 사용할 수도 있습니다.
```bash
npm i -g vercel
vercel
```

### 2) 참여 데이터 영구 저장을 위한 Vercel KV 연결 (중요)
서버리스 환경 특성상 KV(Redis)를 연결하지 않으면 참가자 데이터가 인스턴스 재시작 시 사라질 수 있습니다.
실제 운영(모의훈련 참여 데이터 영구 보관)을 위해서는 아래 절차로 KV를 연결해 주세요.

1. Vercel 프로젝트 대시보드 → **Storage** 탭 → **Create Database** → **KV (Redis)** 선택
2. 생성된 KV를 프로젝트에 **Connect**
3. 연결하면 아래 환경변수가 프로젝트에 자동으로 추가됩니다.
   - `KV_REST_API_URL`
   - `KV_REST_API_TOKEN`
4. 재배포(Redeploy)하면 코드 수정 없이 자동으로 KV에 데이터가 저장됩니다. (`lib/storage.js` 참고)

> KV를 연결하지 않아도 앱은 정상 동작하지만, 참가자 데이터는 임시로만 유지됩니다. 실제 모의훈련에 사용할 경우 반드시 KV 연결을 권장합니다.

## 폴더 구조
```
app/
  page.js              메인+퀴즈+결과 (클라이언트 컴포넌트)
  stats/page.js         통계 페이지 (서버 컴포넌트)
  api/participants/route.js   참가자 등록/조회 API
  layout.js, globals.css
lib/
  questions.js          9문항 문제 풀
  storage.js             KV 연동 + 로컬 폴백 저장소
```

## 문항 수정 방법
`lib/questions.js` 의 `QUESTION_POOL` 배열에서 문항 텍스트, 보기, 정답 인덱스(`correct`, 0부터 시작),
힌트(`hint`), 정답 부연설명(`explanation`)을 자유롭게 수정할 수 있습니다.
